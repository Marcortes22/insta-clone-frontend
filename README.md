# 📸 Instagram Clone – Frontend (Angular)

This project is the frontend of a full-featured Instagram clone built with Angular. It connects to a GraphQL API and includes real-time features, authentication, and an admin panel.

---

## 🚀 Features

### 👤 Authentication

- User registration and login
- OAuth login (Google, Facebook, etc.)
- Password recovery and change
- Email verification

### 🏠 User Profile

- View and edit profile
- Profile picture and bio
- Private/public account setting
- Followers and following list
- Block users

### 📸 Posts

- Upload photo or video
- Add description, hashtags, and location
- Edit or delete own posts
- Like posts
- Save posts to favorites
- View posts by hashtag or location

### 💬 Comments

- Comment on posts
- Reply to comments
- Delete own comments
- Like comments

### 📰 Feed & Explore

- Feed with posts from followed users
- Explore tab with popular content and hashtags
- Search by users, hashtags

### 📥 Direct Messaging

- Real-time chat (WebSocket or GraphQL Subscriptions)
- View and delete conversations
- Send images (optional)

### 🔔 Notifications

- Real-time notifications (new followers, likes, messages)
- Mark as read

### ⚙️ Account Settings

- Language and timezone preferences
- Privacy controls (comments, messages, stories)
- Deactivate or delete account

### 🛠️ Admin Panel

- Manage users and content
- View reports and audit logs
- Access platform statistics

---

## 📡 Technologies

- Angular
- Apollo Angular (GraphQL)
- RxJS
- WebSocket
- TailwindCSS / CSS Modules
